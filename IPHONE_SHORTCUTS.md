# iPhone: быстрые действия Noema

## Один раз на Amvera

1. Загрузить `bot.py`, `requirements.txt` и `amvera.yml`.
2. В настройках приложения включить HTTP/HTTPS-домен. Путь URL добавлять не нужно: `amvera.yml` уже направляет единственный внешний порт `80` на внутренний порт `8080`.
3. В Secrets добавить `QUICK_ACTIONS_BASE_URL` со значением публичного HTTPS-адреса приложения, например `https://your-app.amvera.io`.
4. Пересобрать приложение. Проверка: откройте `https://your-app.amvera.io/healthz` — должен вернуться JSON с `ok: true`.

## Для каждого пользователя

1. В Telegram: `Настройки → iPhone → Подключить iPhone`.
2. Откройте устройство по шестерёнке и нажмите `Параметры Shortcut`: URL и отдельные ключи для Action Button, Double и Triple Back Tap показаны там в моноширинном виде и доступны только владельцу этого чата. ID устройства уже зашит в ключ; вручную его указывать не нужно. Если ключ утрачен, нажмите `Выпустить новый ключ`.
3. Для быстрых команд в приложении Shortcuts сначала добавьте действие `URL`, затем действие `Get Contents of URL`:
   - Method: `POST`
   - Request Body: `JSON`
   - `token`: соответствующий выданный ключ
4. Для `action`, если ему назначена «Голосовая заметка», перед запросом добавить действие `Dictate Text` и передать результат в поле `text` JSON. Для первичной проверки назначьте `action` на «Что осталось сегодня»: это действие не требует текста.
5. Назначить команды в iPhone:
   - Settings → Action Button → Shortcut → команда с `action`;
   - Settings → Accessibility → Touch → Back Tap → Double Tap → команда с `double`;
   - там же Triple Tap → команда с `triple`.

## Поделиться в Noema

1. Создать отдельную команду, включить «На странице экспорта» и разрешить URL, текст, изображения, PDF и файлы.
2. Для URL или текста отправлять на `/api/v1/quick-actions/run` JSON: `token` (ключ «Поделиться в Noema») и `text` (вход команды).
3. Для фото, PDF или файла отправлять на `/api/v1/quick-actions/upload` методом `POST`, тело «Форма»: `token` как текст и `file` как файл из входа команды.
4. Скриншот сделать системно и выбрать «Поделиться → Поделиться в Noema». iPhone не даёт Shortcut бесшумно сделать и переслать снимок экрана по Back Tap.

## Безопасность

- Один ключ работает только для одного подключённого устройства и одного чата.
- Ключ Telegram-бота не используется и не попадает в Shortcut.
- В Telegram можно сменить назначение любого триггера или отключить устройство; после отключения его ключ перестаёт работать.
